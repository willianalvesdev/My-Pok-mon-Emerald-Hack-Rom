# Preferência do projeto

Priorize soluções simples e otimizadas, mesmo que uma mudança afete a compatibilidade com saves antigos. Só adicione código de migração ou de compatibilidade quando o usuário pedir isso explicitamente.

Quando o usuário terminar a mensagem com `CP`, faça commit das alterações solicitadas e envie o commit ao repositório do projeto no GitHub.
